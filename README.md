# 软村饮水

软村饮水是一款用于远程控制饮水机的 Android 应用，提供以下功能：

- 手机号短信验证码登录和密码登录
- 扫码或手动绑定热水、冷水设备
- 远程控制绑定设备的热水、冷水出水
- 混合接水：先接冷水，确认冷水订单结束后自动发送热水指令，热水结束后统一显示消费金额；需同时绑定冷热水设备，冷水状态不明或指令失败时停止后续操作
- 扫描临时设备二维码直接喝水
- 接水请求提交后先显示等待饮水机响应，确认指令下发后才显示可接水；等待超时会提示未确认下发
- 发送接水指令后显示接水状态，结束后根据余额变化显示本次消费金额，倒计时 3 秒自动返回主菜单
- 接水进行中禁止手动返回；正常结束或发生异常后的 3 秒倒计时期间，可点击“返回主页面”提前返回
- 可在设置中开启或关闭出水二次确认
- 查询余额，并在饮水结束或进入“我的”页面时自动更新
- 桌面小组件快捷打开热水、冷水和临时设备扫码功能
- 提供使用帮助和 iOS 用户喝水入口
- 在“设置 → 导出日志”中保存最近 7 天的诊断日志，用于排查接水异常；日志保存在应用私有目录，启动、写入、导出及运行期间每小时清理过期记录
- 日志包含接口状态码、响应消息、脱敏后的接水响应及解析结果，不保存密码、验证码、登录 token 或原始加密报文，设备标识使用摘要关联
- 在“设置 → 版本”中检查 Gitee 发行版并下载 APK；签名安装包由 GitHub Actions 构建后同步到 Gitee，应用源码也从 GitHub main 自动同步到 Gitee main
- 可在版本页面选择每天中午自动检查更新，发现新版时在应用内提示
